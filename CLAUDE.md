# Website-1.0

Agenturauftritt von S & F Webseiten, fünf Beispielprojekte und das interne KI-Studio.
Statisch, ausgeliefert über GitHub Pages (`.github/workflows/pages.yml`).

## Zuerst: das Gedächtnis holen

**Vor der Arbeit an diesem Repo:**

1. Repo `lieboldfabio-hub/Zweites-Gehirn` zur Sitzung hinzufügen
2. Dort `90-Meta/Index.md` lesen — eine Bildschirmseite, die Übersicht über alle Projekte
3. Dann `30-Projekte/Website-1.0.md` lesen — Stand, getroffene Entscheidungen samt
   verworfener Alternativen, Stolperfallen, Landkarte

Das ersetzt die Erkundungstour durch 210 Dateien. Die Regeln für den Vault stehen in
dessen `CLAUDE.md`; nicht den ganzen Vault durchsuchen, sondern Index plus eine Notiz.

**Am Ende der Sitzung:** `30-Projekte/Website-1.0.md` überschreiben, nicht ergänzen.
Was dort nicht steht, muss beim nächsten Mal neu erarbeitet werden.

## Achtung: zwei Auftritte derselben Marke

`sf-webseiten/` in diesem Repo **und** das Repo `premium-motion-web` sind beide der
eigene Auftritt von S & F — einmal statisch, einmal React auf Netlify.
Bei „der Website" immer klären, welche gemeint ist.

## Aufbau

| Pfad | Inhalt |
|---|---|
| `sf-webseiten/` | eigener Auftritt, 8 Seiten, eigene Markenidentität |
| `beispiele/` | fünf Branchenbeispiele, je eigene Gestaltung |
| `kunden/` | Kundenprojekte, werden in eigene private Repos ausgelagert |
| `ai-studio/` | KI-Studio: Node/Express-Backend für Bild- und Videogenerierung |
| `werkzeuge/` | Skripte, u. a. Export eines Kundenprojekts |
