# 10-Notizen

Das eigentliche Gehirn. Hier stehen **dauerhafte Notizen**: je eine Datei, je ein Gedanke, in deinen eigenen Worten.

Merkmale einer guten Notiz hier:
- Der Titel ist eine **Aussage**, keine Überschrift. Nicht „Zinsen", sondern „Zinsen belohnen Geduld, nicht Klugheit".
- Sie ist in einem Jahr ohne Kontext verständlich.
- Sie verlinkt mindestens eine andere Notiz.

Status im Frontmatter:
- `keim` — roher Gedanke, noch nicht durchdacht
- `entwurf` — steht, aber unausgereift
- `fest` — hält, kann zitiert werden

Vorlage: `90-Meta/Vorlagen/Dauerhafte Notiz.md`
