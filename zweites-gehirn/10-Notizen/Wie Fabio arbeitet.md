# Wie Fabio arbeitet

Damit eine neue Sitzung nicht dieselben Fragen stellt.

- **Sprache:** Deutsch, Du-Form. Auch in Commits, READMEs und Notizen.
- **Gerät:** iPad. Kein Terminal, kein lokaler Rechner im Spiel — Lösungen, die einen
  laufenden Desktop voraussetzen, sind für ihn keine Lösungen.
- **Zugang zu Claude:** Claude Code im Web, Repos unter `lieboldfabio-hub`.
- **Kein API-Schlüssel im Einsatz**, alles läuft über das Abo.
- **Rechte auf GitHub:** Claude darf pushen und PRs öffnen, aber **keine Repos anlegen** (403).
  Alles, was ein neues Repository braucht, ist ein Schritt für Fabio.
- **Anspruch an Texte:** keine Fantasiewerte, keine erfundenen Firmen ohne Kennzeichnung.
  Lücken werden sichtbar markiert statt gefüllt.
